# XIAOFUTools 用户手册

本手册按当前 Ribbon 结构说明 XIAOFUTools 的主要入口与工具归类。当前功能区分为 通用 / 编辑 / 数据 / 制图 / 系统 5 组，并提供可选的独立 GIS 工具口袋 标签页。

## 通用

### 顶级入口
- **查看面积**：快速查看当前要素面积。
- **添加预设图层**：以内联图库方式展开常用底图与预设图层。
- **历史影像**：浏览并添加 ArcGIS Wayback 历史影像。

### 数据加载面板
- **批量添加数据**：扫描文件夹中的 GIS 数据并批量添加到地图。
- **下载在线影像**：按范围下载在线影像数据。
- **启动Overture**：进入 Overture 相关工作流。

**批量添加数据支持格式**：Shapefile、FileGDB、GeoJSON、KML 等。

## 编辑

### 顶级入口
- **面积分割**：地图交互式按指定面积分割面要素。

### 属性编辑面板
- **要素顺序编号**：按指定分组字段对要素进行顺序编号。
- **地块中文编号**：使用中文数字对要素进行编号。
- **字段复制工具**：按配置将字段值复制到目标字段。

- **根据范围批量裁剪要素图层**

- **批量定义投影**
- **批量修复几何**

### 界址编辑面板
- **生成四至坐标点**
- **查看起始点**
- **修改起始点**
- **界址点线生成**
- **地图生成界址点线**
- **提取协议线**

### 界址成果面板
- **布局生成坐标表[要素图层版]**：在布局中生成界址坐标表。

## 数据

### 顶级入口
- **计算面积**：批量计算面要素面积并写入指定字段。

### 分析检查面板
- **提取面扣岛**：提取输入面要素中的扣洞。
- **交集汇总表**：统计项目红线与目标图层的交集面积。
- **多图层压盖汇总**：对多个图层的压盖结果进行统计。
- **数据透视**：按字段进行透视统计与汇总。
- **节点距离检查工具**：检查节点间距是否符合要求。
- **图形重叠检查工具**：检查要素是否存在重叠。
- **缝隙检查工具**：检查要素之间是否存在缝隙。

### 格式转换面板
- **要素类转TXT**：导出要素坐标为文本文件。
- **TXT转SHP**：从文本文件创建要素类。
- **特殊坐标转换**：支持多种坐标格式之间的转换。
- **要素图层分组导出KML/KMZ**：按分组字段导出图层。
- **面转DWG[带填充] / 面转DXF[带填充]**：导出 CAD 文件。

### 数据整备面板
- **批量合并SHP**：批量扫描并合并 SHP。
- **MDB批量格式转换**：批量将 MDB 转换为文件地理数据库、移动地理数据库或 XML Workspace Document。
- **镜像数据库**：复制数据库结构，不复制数据。
- **属性表建库**：根据 Excel 模板创建文件地理数据库。
- **属性表建SHP**：根据 Excel 模板批量创建 Shapefile。
- **SHP输字段表**：导出 SHP 字段结构到 Excel。
- **输出数据库属性结构表**：导出数据库结构说明。

**属性表建库/建SHP模板位置**：`Assets/Data/Excel模板/`

## GIS 工具口袋

GIS 工具口袋由原 GIS Toolbox 整合而来，用于集中收纳和快速调用个人常用 GIS 工具。现在只需安装 XIAOFUTools，无需再单独安装 GIS Toolbox；首次使用时，打开该标签页中的“管理”入口添加内容。

### 可添加内容
- ArcGIS 工具箱：.atbx、.tbx、.pyt
- ArcGIS Pro 内置命令和地图工具
- 自定义工具组及其中的常用命令

### 日常使用
- 可按工具箱、工具集或平铺方式组织功能区入口。
- 可搜索已添加工具，回车或选择结果即可打开。
- 可在管理窗口中调整顺序、隐藏不常用工具、编辑自定义分组，并导入或导出完整工具包。
- 最多可展示 32 个动态工具入口；超出部分请通过搜索或调整显示内容调用。

### 显示或隐藏标签页

打开 **XIAOFU工具箱 > 系统 > 设置**，勾选或取消勾选“显示 GIS 工具口袋标签页”即可即时控制标签页显示。
