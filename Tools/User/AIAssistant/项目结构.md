## 模块说明

### 1. Database (数据库管理层)
**职责**: 管理AI服务配置、对话历史和会话记录

**DatabaseManager.cs** (430行)
- 单例模式实现
- SQLite数据库初始化和表结构创建
- AI服务配置CRUD操作
- 对话历史管理
- 会话管理
- 工具调用记录

**Models.cs** (60行)
- `AIServiceConfig`: AI服务配置模型
- `ConversationMessage`: 对话消息模型
- `Session`: 会话信息模型
- `ToolCallRecord`: 工具调用记录模型

### 2. Services (AI服务层)
**职责**: 封装AI API调用,支持多种AI服务

**IAIService.cs** (55行)
- 定义AI服务统一接口
- `SendMessageStreamAsync`: 流式响应
- `SendMessageAsync`: 完整响应
- `ValidateApiKeyAsync`: 密钥验证

**OpenAICompatibleService.cs** (135行)
- 实现OpenAI兼容API调用
- 支持DeepSeek、SiliconFlow等服务
- 支持OpenAI原生Tools协议(tool_choice / tool_calls)
- 流式SSE数据解析
- HTTP请求管理

### 3. Agent (GIS Agent层)
**职责**: 协调AI服务和GIS工具,实现智能GIS助手

**IGISTool.cs** (60行)
- GIS工具接口定义
- JSON Schema参数定义
- 工具执行结果封装

**GISAgentCore.cs** (220行)
- Agent核心协调器
- 工具注册和管理
- 消息历史构建
- 流式对话处理
- 工具调用检测和执行
- 会话管理

**Tools/ExampleGISTool.cs** (200行)
- 示例工具实现
- GetMapLayersTool: 获取图层列表
- BufferAnalysisTool: 缓冲区分析
- CoordinateTransformTool: 坐标转换

### 4. UI (用户界面)
**职责**: 提供现代化的聊天交互界面

**chat.html** (450行)
- 响应式聊天界面
- 渐变色现代设计
- 流式输出显示
- 打字动画效果
- 建议问题卡片
- WebView2消息通信

**AIAssistantDockPaneView.xaml** (40行)
- WPF DockPane视图
- WebView2控件嵌入
- 加载指示器

**AIAssistantDockPaneView.xaml.cs** (180行)
- WebView2初始化
- 消息通信桥接
- 流式响应处理
- 错误处理

### 5. 视图模型和按钮
**AIAssistantDockPaneViewModel.cs** (90行)
- DockPane生命周期管理
- Agent实例管理
- HTML路径解析

### 6. Application (应用编排层)
**职责**: 把业务编排从视图代码后台中解耦

**AIAssistantApplicationService.cs**
- 统一处理发送消息流程
- 统一处理会话加载/删除/切换
- 统一处理模型列表与设置刷新
- 统一处理Python执行与结果持久化

**AIAssistantButton.cs** (25行)
- 工具箱按钮实现
- DockPane激活

## 设计特点

1. **模块化架构**: 清晰的分层设计,易于扩展和维护
2. **现代UI**: 渐变色、动画效果、响应式设计
3. **流式输出**: 实时显示AI回复,提升用户体验
4. **持久化存储**: SQLite管理配置和历史
5. **可扩展**: 插件式GIS工具注册机制
6. **双AI支持**: 内置DeepSeek和SiliconFlow
7. **上下文管理**: 完整的多轮对话支持

## 使用流程

1. 用户点击"AI助手"按钮
2. 打开DockPane,显示WebView2界面
3. 用户输入问题
4. 前端通过postMessage发送到C#
5. C# Agent处理并调用AI服务
6. 流式返回结果到前端
7. 前端实时显示回复
8. 保存对话到数据库
