# 遍历要素功能设计文档

- 日期：2026-03-29
- 项目：XIAOFUTools
- 主题：参考 ArcMap Data Reviewer 的“浏览要素/遍历要素”能力，为 ArcGIS Pro 插件新增独立遍历要素窗格
- 参考资料：ArcGIS Desktop 官方文档《Data Reviewer 快速浏览》中的“浏览要素”窗口，文档描述其可用于“浏览地图上选定的要素集，以从视觉上检查数据”，并支持逐条浏览结果与定位要素。

## 1. 背景与目标

当前项目缺少一个面向人工目视检查的“逐条浏览要素”工具。用户希望参考 ArcMap Data Reviewer 的“浏览要素”交互方式，在 ArcGIS Pro 中提供一个独立停靠窗格，用于对当前关注图层执行按顺序遍历、自动定位与高亮检查。

本次功能目标：

1. 支持对**当前选中图层**的全部要素进行顺序遍历。
2. 默认按 **ObjectID 升序**构建遍历快照。
3. 提供**首条 / 上一条 / 下一条 / 末条**导航能力。
4. 每次导航时自动**定位并闪烁高亮当前要素**。
5. **不修改地图选择集**，保持与编辑/选择工作流解耦。
6. 采用项目标准 **Button + DockPane + View + ViewModel** 架构与统一样式。

## 2. 已确认的需求边界

### 2.1 数据范围

- 默认作用对象：**当前选中图层的全部要素**。
- 图层类型限制：必须为 `FeatureLayer`。
- 排序规则：按 ObjectID 升序。
- 本期不支持跨多个图层混合遍历。
- 本期不支持按当前选择集遍历。
- 本期不支持自定义排序字段。

### 2.2 地图交互

- 每次切换到目标要素时：
  - 自动定位到要素；
  - 自动执行视觉高亮/闪烁反馈；
  - 不改选择集；
  - 不依赖地图当前选择变化事件驱动导航。

### 2.3 界面与入口

- 实现为**独立停靠窗格**。
- 窗格支持：
  - 当前图层状态显示；
  - 当前序号 / 总数显示；
  - 刷新快照；
  - 首条 / 上一条 / 下一条 / 末条 四个导航按钮；
  - 日志输出区域。
- 工具注册到 **通用组**。
- 本期**不接入右键菜单**。

## 3. 方案比较

### 方案 A：预加载 OID 快照并维护当前索引（选定方案）

**做法**
- 打开窗格或刷新时，一次性读取当前选中图层全部 ObjectID。
- 将 OID 列表缓存到 ViewModel。
- 使用当前索引驱动首条、上一条、下一条、末条导航。
- 每次导航仅查询当前 OID 对应单条要素。

**优点**
- 行为稳定，可预测性强。
- 导航开销低，适合高频逐条检查。
- 最接近 Data Reviewer 的“浏览结果集”思路。
- 便于显示“第 N 条 / 共 M 条”。

**缺点**
- 图层数据变化后，快照可能失效，需要刷新或自动重建。

### 方案 B：不缓存快照，实时查询前后要素

**做法**
- 每次点击导航按钮时，根据当前 OID 实时查询上一条/下一条记录。

**优点**
- 状态少，实现表面更轻。

**缺点**
- 查询逻辑更复杂。
- 在定义查询、数据变化、游标状态变化场景下稳定性较差。
- 不利于准确显示总数和当前位置。

### 方案 C：窗格内嵌结果表格 + 导航联动

**做法**
- 在窗格中显示完整要素列表，配合导航按钮与地图联动。

**优点**
- 可视化更强。

**缺点**
- UI 更重，实现量更大。
- 与本次“快速逐条浏览”目标相比存在过度设计。

### 结论

采用**方案 A**作为正式实现基线：

> 独立停靠窗格 + 预加载 OID 列表 + 地图定位闪烁 + 首条/上一条/下一条/末条导航。

## 4. 总体设计

### 4.1 模块位置

建议新增目录：

```text
Tools/Common/FeatureTraversal/
├── FeatureTraversalButton.cs
├── FeatureTraversalDockPane.cs
├── FeatureTraversalDockPaneView.xaml
├── FeatureTraversalDockPaneView.xaml.cs
└── FeatureTraversalDockPaneViewModel.cs
```

将功能归类到 `Tools/Common`，与“通用组”菜单位置一致。

### 4.2 组件职责

#### FeatureTraversalButton
- 负责工具入口。
- 执行授权检查。
- 打开遍历要素窗格。

#### FeatureTraversalDockPane
- 负责 DockPane 生命周期。
- 激活并承载视图。

#### FeatureTraversalDockPaneView
- 负责声明式 UI。
- 仅保留必要界面事件桥接。

#### FeatureTraversalDockPaneViewModel
- 负责当前图层解析。
- 负责 OID 快照构建与重建。
- 负责导航状态与命令启停。
- 负责当前要素读取、地图定位、闪烁高亮、日志记录、错误恢复。

## 5. 核心数据模型

### 5.1 运行时状态

建议 ViewModel 维护以下核心状态：

- `CurrentLayerName`：当前快照对应图层名。
- `StatusMessage`：状态说明，如“未检测到选中图层”“已加载 152 条要素”。
- `CurrentIndex`：当前索引（0-based）。
- `TotalCount`：快照总数。
- `CurrentObjectId`：当前记录 OID。
- `OidSnapshot`：已缓存的 OID 列表。
- `IsBusy`：是否正在刷新/导航。
- `CanNavigatePrevious` / `CanNavigateNext`：按钮状态。
- `LogContent`：日志文本。

### 5.2 图层解析规则

“当前选中图层”采用以下优先级：

1. TOC 中被用户选中的图层；
2. 若无明确选中图层，则视为无有效目标；
3. 若选中对象不是要素图层，则视为无效。

此规则可避免误将地图中所有图层作为目标，提高行为确定性。

## 6. 数据流设计

### 6.1 打开窗格 / 刷新快照

1. 用户点击入口按钮打开窗格。
2. ViewModel 在 MCT 中解析当前选中图层。
3. 校验图层是否存在、是否为要素图层、是否可访问。
4. 查询该图层全部 ObjectID，并按升序构建快照。
5. 若快照为空，则进入不可导航状态并提示“图层中无要素”。
6. 若快照有效，则默认切换到第 1 条记录。
7. 更新 `第 N 条 / 共 M 条` 显示。
8. 执行目标要素定位与高亮。

### 6.2 导航

1. 用户点击首条 / 上一条 / 下一条 / 末条。
2. ViewModel 仅调整当前索引，不重新扫描整层。
3. 读取当前索引对应的 OID。
4. 查询单条要素。
5. 获取几何后执行地图定位与闪烁高亮。
6. 更新状态与日志。

### 6.3 失效恢复

以下情况视为快照失效或记录失效：

- 图层被移除或失去引用；
- 记录已删除；
- 几何为空；
- 图层状态变化导致记录不可访问。

处理策略：

- 单条记录失效：记录日志，并跳过到下一条可用记录。
- 多条连续失效：继续尝试，直到找到有效要素或耗尽快照。
- 快照整体明显失效：自动重建快照；若仍失败，则清空导航状态并提示原因。

## 7. 地图定位与高亮策略

### 7.1 定位策略

每次导航时：

- 若要素有几何范围，则优先缩放到几何范围；
- 若范围过小，则以适度比例放大到可视检查尺度；
- 若为点要素，则围绕点进行适度缩放；
- 若为线/面要素，则以包络范围为主。

### 7.2 高亮策略

- 使用 ArcGIS Pro 可用的闪烁或短时高亮反馈机制。
- 不改选择集。
- 若 API 无统一闪烁接口，则退化为短时地图定位 + 高亮覆盖反馈。

## 8. UI 设计

### 8.1 窗格布局

遵循项目统一布局：

1. 顶部状态区：显示当前图层、状态信息、当前位置；
2. 操作区：刷新、首条、上一条、下一条、末条；
3. 进度/忙碌提示区：可选；
4. 日志区：显示运行日志；
5. 底部按钮区：保留帮助位，若本期无帮助内容可先不启用独立帮助命令。

### 8.2 建议字段展示

本期最小展示集合：

- 当前图层名；
- 当前 OID；
- 第 N 条 / 共 M 条；
- 当前状态说明；
- 日志内容。

不增加字段明细表，不增加属性编辑能力。

## 9. 错误处理与线程模型

### 9.1 线程模型

所有 ArcGIS Pro API 调用必须放入 `QueuedTask.Run` 中，包括：

- 图层解析；
- 表查询；
- OID 快照构建；
- 单条要素读取；
- 几何范围获取；
- 地图定位相关 GIS 操作。

UI 属性更新回到 ViewModel 正常属性赋值流程。

### 9.2 错误处理原则

遵循项目统一规范：

- 所有导航和刷新逻辑使用 `try/catch` 包裹；
- 错误优先写入日志区；
- 必要时弹出明确错误消息；
- 对可恢复错误优先自动恢复，不直接终止整个窗格；
- 对不可恢复错误切换为不可导航状态，并显示原因。

以下内容不纳入本期：

- 多图层联合遍历；
- 按选择集遍历；
- 自定义排序字段；
- 条件过滤器构建器；

- Reviewer 表写入；

## 12. 验收标准

满足以下条件即视为本期完成：

1. 可通过工具栏按钮打开“遍历要素”停靠窗格。
2. 当存在有效当前选中要素图层时，可成功加载全部 OID 快照。
3. 默认进入第 1 条要素。
4. 首条 / 上一条 / 下一条 / 末条导航可正常工作。
5. 每次导航都会自动定位并给予高亮反馈。
6. 不会修改地图当前选择集。
7. 图层为空、无选中图层、图层失效等异常情况有明确提示。
8. 日志能够反映刷新、导航、异常与跳过情况。
9. 实现符合项目 MVVM、样式、线程与异常处理规范。
